Freezely · Add Item redesign

The goal: a calm single-column flow where the common case is type a name → Save, and everything optional gets out of the way. HTML approximations of how React Native would render.

Direction A · Grouped & guided · shipped

Same fields, organised into calm sections with real breathing room — everything laid out directly (no collapsed "More options"). This is what shipped in AddItemScreen.js / EditItemScreen.js.

  • Item — name on top; scan & photo shrink to two quiet pills below it; the coverage line stays as a small caption.
  • Storage — compartments wrap (no hidden sideways scroll); quantity is a − 1 + stepper with unit chips beside it.
  • Dates — Frozen defaults to Today; Best before is optional with a "leave empty to auto-calculate" hint.
  • Package # · Notes — shown as their own sections, always visible.

Direction B · Minimal fast-add

Stripped to the bone for speed — optimised for the 2-second add. Best if most items are added quickly with defaults. Same data underneath; just far less on screen.

  • Big name field on top with scan & photo as inline icons in the field (Pro dot, no labels, no paragraph).
  • Compartment chips wrap right under it; quantity stepper + unit on one quiet line.
  • Frozen date collapses to a one-line “Frozen today · Edit”.
  • Everything else — best before, package #, notes — lives behind one More options card.
